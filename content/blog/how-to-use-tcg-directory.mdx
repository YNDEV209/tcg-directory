## What is TCG Directory?

TCG Directory is a free, comprehensive trading card database that covers five major card games in one place:

- **Pokemon TCG** — 20,000+ cards from Base Set to the latest expansions
- **Magic: The Gathering** — 30,000+ cards across all Standard sets
- **Yu-Gi-Oh!** — 14,000+ cards including monsters, spells, and traps
- **One Piece TCG** — 2,000+ cards from all booster and starter sets
- **Gundam Card Game** — 600+ cards from every available set

Whether you're building a deck, checking prices, or just browsing your favorite cards, here's how to get the most out of the site.

## Searching for Cards

### Basic Search

The search bar at the top of the [homepage](/) lets you find any card by name. Just start typing and results appear instantly. Search works across all card names in the selected game — partial matches are supported, so typing "Char" will find Charizard, Charmander, and more.

### Switching Games

Use the game tabs below the header to switch between Pokemon, MTG, Yu-Gi-Oh!, One Piece, and Gundam. Each game has its own card pool, filters, and sorting options tailored to that game's mechanics.

## Using Filters

The filter sidebar (tap "Filters" on mobile) lets you narrow down results by:

### Type / Color / Attribute
- **Pokemon**: Filter by energy type (Fire, Water, Grass, etc.)
- **MTG**: Filter by color (White, Blue, Black, Red, Green)
- **Yu-Gi-Oh!**: Filter by attribute (DARK, LIGHT, EARTH, etc.)
- **One Piece**: Filter by card color (Red, Green, Blue, etc.)

### Supertype / Card Type
Filter by the card's category:
- **Pokemon**: Basic, Stage 1, Stage 2, GX, V, VMAX, ex
- **MTG**: Creature, Instant, Sorcery, Enchantment, Planeswalker
- **Yu-Gi-Oh!**: Normal, Effect, Fusion, Synchro, Xyz, Link, Spell, Trap

### Rarity
Find commons for budget builds or hunt for ultra rares and secret rares.

### Set
Browse cards from a specific expansion, booster pack, or starter deck. You can also visit the [Sets page](/sets) to browse all sets across every game.

### Stats
Filter by HP, power level, or mana value depending on the game.

## Sorting Options

The default **Featured** sort highlights the rarest and most valuable cards first. You can also sort by:

- **Name** (A-Z or Z-A)
- **HP / Power** (highest or lowest first)
- **Price** (most or least expensive)
- **Set** (grouped by expansion)

## Viewing Card Details

Click any card to see its full detail page, which includes:

- **High-resolution card image**
- **Card stats** — type, HP, attacks, abilities, weaknesses, resistances
- **Market prices** — current values from TCGplayer, Cardmarket, and other sources
- **Set information** — which sets/boosters contain this card
- **Evolution chain** (Pokemon) — links to pre-evolutions and evolutions

## Saving Favorites

Found a card you love? Click the heart icon to save it to your favorites. Your favorites are stored locally in your browser — no account needed. Visit the Favorites page to see all your saved cards in one place.

## Comparing Cards

Can't decide between two cards? Use the compare feature:

1. Click the compare icon on any card (the overlapping squares icon)
2. Add up to 4 cards to compare
3. Click "Compare Now" in the floating bar at the bottom
4. See a side-by-side comparison of stats, types, attacks, and prices

This is especially useful for deck building when you're choosing between similar cards.

## Building Decks

TCG Directory includes a built-in deck builder:

1. Go to the **Decks** page from the header
2. Create a new deck and choose your game
3. Search for cards and add them to your deck
4. Adjust card counts (most games allow up to 4 copies)
5. View deck stats including type distribution and card count

Your decks are saved locally, so they persist between sessions.

## Browsing Sets

The [Sets page](/sets) shows all available expansions organized by release date. Click any set to browse all cards in that expansion. Each set page shows:

- Set logo and release date
- Total card count
- All cards in the set with images and rarity

For games like Yu-Gi-Oh! where cards appear in many different sets, each card's detail page shows **all sets** that card has been printed in, with per-set rarity and pricing.

## Tips for Power Users

- **Bookmark filtered views**: The URL updates as you filter, so you can bookmark specific searches (e.g., all Fire-type Pokemon sorted by price)
- **Use keyboard shortcuts**: Press Enter in the search bar to search, and the × button to clear quickly
- **Check multiple games**: Some card concepts span games — compare Yu-Gi-Oh! Dragon cards with Pokemon Dragon types
- **Track price trends**: Check card detail pages regularly to monitor price changes on cards you're interested in

## Getting Started

Head to the [homepage](/) and start exploring! Pick your favorite game, search for a card you know, and discover what TCG Directory has to offer. Whether you're a collector, competitive player, or casual fan, there's something here for everyone.
